# Customer Core Module

## Overview
The `customer` module is responsible for managing the profiles and data of all the suppliers/customers registered in the system.

## Key Components
- **`CustomerListScreen` (`customer_list_screen.dart`)**: Displays a directory of all registered customers. It provides search and filter capabilities to quickly find a specific customer's profile.
- **`CustomerFormScreen` (`customer_form_screen.dart`)**: The data entry form for onboarding new customers or updating existing customer details, such as their name, contact information, and address.
