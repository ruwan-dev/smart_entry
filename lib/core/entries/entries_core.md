# Entries Core Module

## Overview
The `entries` module is a core part of the application responsible for managing the daily records of tea leaf collections, advances, and item issuances.

## Key Components
- **`DailyEntriesScreen` (`daily_entries_screen.dart`)**: Displays a list of all recorded daily entries. It provides functionalities to view, filter, and manage the history of collections.
- **`DailyEntryFormScreen` (`daily_entry_form_screen.dart`)**: A form interface used to record a new daily entry or edit an existing one. It captures critical data such as the customer's ID, net weight of tea leaves, cash advances, and quantities of fertilizers or tea packets issued.
