# Splash Feature

## Overview
The `splash` feature contains the initial screen displayed when the Smart Entry application is launched.

## Key Components
- **`SplashScreen` (`splash_screen.dart`)**: Displays the app's logo and branding while performing essential initialization tasks in the background. It typically handles checking session states, verifying network connectivity, and deciding whether to route the user to the `LoginScreen` or directly to the `DashboardScreen`.
